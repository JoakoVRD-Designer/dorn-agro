Instalar el equipo DORN

Firmware 1.4.0 para ESP32-S3 Super Mini, ya compilado y probado. No necesitas Arduino IDE.

Este navegador no puede conectarse por USB. Abre esta página en Chrome o Edge en un computador (Windows, Mac o Linux).

  1. 1

    Cargar el firmware

    Conecta la placa al computador con un cable USB-C de datos (algunos cables solo cargan) y toca el botón. Elige el puerto que aparece (USB JTAG/serial o «ESP32-S3»).

    Usa Chrome o Edge en un computador.Abre esta página con https.
    ¿No aparece el puerto o falla la carga?
    1. Prueba otro cable USB-C: muchos solo cargan y no transmiten datos.
    2. Pon la placa en modo carga: mantén BOOT, toca RESET, suelta BOOT y vuelve a intentar.
    3. En Windows, si no aparece ningún puerto, prueba otro puerto USB del computador.
    4. Al terminar, toca RESET una vez para que arranque el firmware nuevo.
  2. 2

    Conectar la consola

    Con la placa conectada, abre la consola para configurarla y ver lo que hace.

    Sin conectar
  3. 3

    Configurar el WiFi

    Red 2,4 GHz. Agrega el hotspot de tu celular como respaldo: si el WiFi del lugar falla, el equipo se pasa solo.

    La placa se reinicia después de guardar cada red (unos segundos).

    ¿Prefieres hacerlo desde el celular o cambiar el WiFi más adelante?
    1. Sin WiFi guardado, el equipo abre solo su red DORN-AGRO-xxxx (LED azul).
    2. Para cambiar de WiFi cuando quieras: toca BOOT una vez (toque corto), o en la app Equipo → Cambiar WiFi del equipo. La red queda abierta 10 minutos y el equipo sigue funcionando.
    3. Conéctate a esa red con el celular y abre http://192.168.4.1: elige tu WiFi, una red de respaldo y los sensores instalados.
    4. Mantener BOOT 3 segundos borra todas las redes guardadas.
  4. 4

    Revisar y vincular

    Toca Diagnóstico: debe decir WiFi CONECTADO y Servidor CONECTADO, con el LED de la placa en verde. Luego vincula el equipo a tu cuenta.

    ¿«Probar bomba» no hace clic, o el relé hace lo contrario?

    El equipo viene listo para el relé común de Arduino (se activa con nivel bajo). Si el tuyo no responde, prueba el otro tipo; queda guardado en la placa.

¿Qué significa el LED?

  • Amarillo parpadeando: buscando WiFi
  • Azul parpadeando: portal abierto (red DORN-AGRO-…)
  • Celeste: WiFi listo, conectando al servidor
  • Verde: en línea, listo para usar
  • Verde parpadeando: regando
  • Rojo parpadeando: protección activada
